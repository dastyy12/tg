# Инструкция по развертыванию Hydra Bot на Render

## 📋 Предварительные требования

1. **Аккаунт на Render.com** - зарегистрируйтесь на [render.com](https://render.com)
2. **GitHub репозиторий** - загрузите код в GitHub
3. **Telegram Bot Token** - получите токен от @BotFather

## 🚀 Пошаговая инструкция развертывания

### Шаг 1: Подготовка репозитория

1. Убедитесь, что все файлы добавлены в репозиторий:
   ```
   ├── bot.py
   ├── config.py
   ├── database.py
   ├── keyboards.py
   ├── signals_simulator.py
   ├── app.py
   ├── requirements.txt
   ├── runtime.txt
   ├── Procfile
   ├── gunicorn.conf.py
   ├── render.yaml
   ├── .gitignore
   └── DEPLOYMENT.md
   ```

2. Закоммитьте и запушьте изменения:
   ```bash
   git add .
   git commit -m "Prepare for Render deployment"
   git push origin main
   ```

### Шаг 2: Создание сервиса на Render

1. **Войдите в Render Dashboard**
   - Перейдите на [dashboard.render.com](https://dashboard.render.com)

2. **Создайте новый Web Service**
   - Нажмите "New +"
   - Выберите "Web Service"
   - Подключите ваш GitHub репозиторий

3. **Настройте сервис:**
   - **Name**: `hydra-bot` (или любое другое имя)
   - **Environment**: `Python 3`
   - **Region**: выберите ближайший к вам регион
   - **Branch**: `main`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python app.py`

### Шаг 3: Настройка переменных окружения

В настройках сервиса добавьте следующие Environment Variables:

| Variable | Value | Описание |
|----------|-------|----------|
| `BOT_TOKEN` | `ваш_токен_бота` | Токен от @BotFather |
| `ADMIN_CHAT_ID` | `-4827638107` | ID админ-чата |
| `PYTHON_VERSION` | `3.11.0` | Версия Python |

### Шаг 4: Настройка плана

- **Plan**: Free (для начала)
- **Auto-Deploy**: Enabled
- **Health Check Path**: `/health`

### Шаг 5: Запуск развертывания

1. Нажмите "Create Web Service"
2. Render автоматически начнет сборку и развертывание
3. Дождитесь завершения процесса (обычно 2-5 минут)

## 🔧 Проверка работоспособности

### 1. Проверка веб-интерфейса
- Откройте URL вашего сервиса (например: `https://hydra-bot.onrender.com`)
- Должна появиться страница "Hydra Bot is running!"

### 2. Проверка health check
- Откройте `/health` (например: `https://hydra-bot.onrender.com/health`)
- Должен вернуться ответ "OK"

### 3. Проверка бота
- Найдите вашего бота в Telegram
- Отправьте команду `/start`
- Бот должен ответить

## 🛠️ Устранение неполадок

### Проблема: Бот не отвечает
**Решение:**
1. Проверьте логи в Render Dashboard
2. Убедитесь, что `BOT_TOKEN` установлен правильно
3. Проверьте, что бот не заблокирован

### Проблема: Ошибка сборки
**Решение:**
1. Проверьте `requirements.txt` - все зависимости должны быть совместимы
2. Убедитесь, что используется правильная версия Python
3. Проверьте логи сборки

### Проблема: Сервис не запускается
**Решение:**
1. Проверьте `app.py` - убедитесь, что код корректен
2. Проверьте переменные окружения
3. Убедитесь, что порт настроен правильно
