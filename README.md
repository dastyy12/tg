# HYDRA - Крипто-инвестиционный терминал Telegram-бот

🔐 Закрытый крипто-инвестиционный терминал HYDRA, имитирующий работу профессиональной торговой платформы.

## 🚀 Возможности

### Для пользователей:
- 🔐 Доступ только по инвайт-коду
- 💳 Привязка кошелька USDT (BEP-20)
- 💰 Система депозитов и выводов
- 📈 Три инвестиционные стратегии:
  - 🧠 AI-арбитраж (до 8% доходности)
  - 💧 Пулы ликвидности (до 3% доходности)
  - 📊 Сигналы аналитиков (до 10% доходности)
- 📡 Эксклюзивные торговые сигналы
- 🧠 Портфель с отслеживанием доходности
- ⚙️ Профессиональный интерфейс

### Для администратора:
- 📱 Админ-чат для управления
- ✅ Подтверждение депозитов
- 💰 Начисление доходности
- 🔁 Управление выводами
- 📊 Мониторинг всех операций

## 📋 Требования

- Python 3.8+
- Telegram Bot Token
- SQLite3 (встроен в Python)

## 🛠️ Установка

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd арбитраж
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Создайте файл .env:**
```bash
cp env_example.txt .env
```

4. **Настройте переменные окружения в .env:**
```env
BOT_TOKEN=your_bot_token_here
ADMIN_CHAT_ID=your_admin_chat_id_here
```

## 🔧 Настройка

### Получение Bot Token:
1. Найдите @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен в .env

### Получение Admin Chat ID:
1. Добавьте бота в группу или начните с ним чат
2. Отправьте любое сообщение боту
3. Перейдите по ссылке: `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates`
4. Найдите `"chat":{"id":123456789}` - это ваш Admin Chat ID

## 🚀 Запуск

```bash
python bot.py
```

## 📱 Использование

### Для пользователей:

1. **Регистрация:**
   - Отправьте `/start` боту
   - Введите инвайт-код (по умолчанию: `HYDRA2024`, `ARBITRAGE`, `LIQUIDITY`)
   - Привяжите кошелек USDT (BEP-20)

2. **Пополнение:**
   - Перейдите в раздел "💰 Депозит"
   - Отправьте USDT на указанный адрес
   - Пришлите хэш транзакции
   - Дождитесь подтверждения от администратора

3. **Активация стратегий:**
   - Перейдите в "📈 Стратегии"
   - Выберите подходящую стратегию
   - Активируйте на нужную сумму

4. **Получение сигналов:**
   - Активируйте стратегию "Сигналы аналитиков"
   - Перейдите в "📡 Сигналы"
   - Получайте эксклюзивные торговые сигналы

### Для администратора:

1. **Подтверждение депозитов:**
   - Получите уведомление в админ-чате
   - Нажмите "✅ Подтвердить депозит"

2. **Начисление доходности:**
   - Используйте кнопку "💰 Начислить доходность"
   - Доходность рассчитывается автоматически

3. **Управление выводами:**
   - Получите запрос на вывод
   - Подтвердите или отклоните операцию

## 🗄️ База данных

Бот использует SQLite для хранения данных:
- `users` - пользователи и их кошельки
- `deposits` - депозиты и их статусы
- `user_strategies` - активные стратегии пользователей
- `yields` - начисленная доходность
- `withdrawals` - запросы на вывод

## 🔐 Безопасность

- Все операции требуют подтверждения администратора
- Валидация адресов кошельков
- Проверка балансов перед операциями
- Логирование всех действий
